# 起動引数のガイド（管理者・開発者向け）

通常利用ではアプリをダブルクリックすればよく、コマンド入力は不要です。最初の採点は[はじめに](getting-started.md)、AIへの指示文を書く方法は[独自の評価指示を書く](custom-evaluator-guide.md)を参照してください。

**確認日：2026-11-07。公開`v0.8.6`と現行ソース`0.8.8`で、`--prompt`の扱いが違います。** 起動を依頼する文章と、採点に使う指示文は別物です。

## 版による違い

| 引数 | 公開`v0.8.6` | 現行ソース`0.8.8`（未公開） |
|---|---|---|
| `--input` | 入力Excelの場所を設定して読込 | 同じ |
| `--prompt` | 指定したUTF-8テキストを読み込み、利用者が対象の評価へコピーする旧方式 | 引数・ファイルを検証して受理しますが、読み込んだ内容は画面に表示せず、どの評価にも適用しません |

現行ソースでは、指示文を**2 採点設計 → 通常評価の編集領域 → Prompt**で直接編集してください。`--prompt`を付けても採点基準にはなりません。公開版の通常評価は**設定 → 通常評価**にあります。

## 起動形式

公開`v0.8.6`の単一EXE：

```text
StudyReportEvaluator-win-x64.exe --input "<xlsx-path>" --prompt "<txt-path>" [--prompt "<txt-path>" ...]
```

ZIPを展開したEXE：

```text
StudyReportEvaluator.App.exe --input "<xlsx-path>" --prompt "<txt-path>" [--prompt "<txt-path>" ...]
```

入力だけを指定する場合：

```powershell
& "C:\配布 アプリ\StudyReportEvaluator-win-x64.exe" --input "C:\授業 データ\回答.xlsx"
```

公開版は[GitHub Releases](https://github.com/dahatake/StudyReport-Evaluator/releases/tag/v0.8.6)から入手します。`0.8.8`は未公開のローカル候補です。公開版のclean-host試験CH-01〜06と本人loginは公開前に実施していません。[検証範囲](getting-started.md#v086の検証範囲)を確認してください。

## 引数の規則

- `--input`は0または1回、`--prompt`は0回以上です。`--run`や`--resume`はありません。
- オプション名は大文字・小文字を区別しません。
- 空白や日本語を含むパスは引用符で囲んでください。
- 相対パスは起動元の作業フォルダーを基準にします。EXEの場所や抽出先を基準にしません。
- 同じPromptファイルの重複は最初の1件だけを使い、指定順を保持します。
- 未知のオプション、重複した`--input`、値の不足、不正なパス、`.txt`以外の`--prompt`は起動エラーです。
- 指示文ファイルはstrict UTF-8、BOMあり／なしを受理します。長さは1〜32,767 UTF-16 code units（内部の文字数単位）で、空・不正な文字コード・読込失敗は拒否します。現行ソースでも使われない引数だからといって検証を省略しません。

## 自動処理の注意

**起動引数ではAI評価を開始しません。** 一方、アプリ本来の起動時処理は既存ログインを自動確認し、未認証ならブラウザー認証を1回だけ自動開始します。「引数で採点しない」は「通信しない」という意味ではありません。

自動でブラウザーを開かせない必要がある場合、管理者は`STUDY_REPORT_EVALUATOR_AUTO_COPILOT_LOGIN`を`0`または`false`に設定できます。既存ログインの確認自体は行います。パスワードやトークンを引数・指示文へ入れないでください。

## 起動をエージェントへ依頼する例

以下は**アプリを開くだけの依頼**です。採点用の指示文ではありません。`<...>`を実際の場所に置き換えてください。

```text
ローカルのStudyReport Evaluatorを、入力Excelを指定して起動してください。

アプリ: "<EXEの完全なパス>"
入力Excel: "<標準.xlsxの完全なパス>"

条件:
- ファイルの存在と拡張子だけを確認し、回答本文を開いたりチャットに表示したりしない。
- 入力や既存ファイルは変更しない。
- --inputを1回だけ使い、各パスを引用符で囲む。
- 起動元の作業フォルダーを維持する。
- GUIが開いたら終了し、画面操作やAI評価を行わない。
- アプリ自身の起動時ログイン確認・自動ブラウザー認証は別に動く場合がある。
- ファイルがない場合は推測せず、その場所が見つからないと報告する。
```

指示文をファイルで保管している場合は、現行ソースではその内容を採点設計のCustom欄へ手動で貼り付けます。通常Customには`{回答}`と`{評価項目}`が必要です。実際の学生の回答・氏名・秘密情報を指示文や依頼チャットへ貼り付けないでください。
